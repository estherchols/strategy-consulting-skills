# Executive Storyline

Communicate the answer first, then support it with logically grouped arguments, so a busy executive gets the point in 30 seconds.

## Step 1: Find the governing thought
Write the single sentence the audience must remember. It should be a recommendation or conclusion, not a topic.
- ❌ "Market analysis of the European EV charging sector."
- ✅ "We should enter the German EV charging market through a partnership with a utility, reaching €120M revenue by 2030."

## Step 2: Build the pyramid (Pyramid Principle)
```
Governing thought (answer)
├── Key argument 1 ── supporting data/analyses
├── Key argument 2 ── supporting data/analyses
└── Key argument 3 ── supporting data/analyses
```
Rules:
- **Answer first:** conclusion before explanation.
- **Group and summarize:** each level summarizes the ideas below it.
- **MECE arguments:** 3 (sometimes 2–4) arguments that together prove the governing thought without overlap.
- **Logical order:** chronological, structural, or by importance. Or **deductive** (premise → premise → conclusion) when the audience needs to follow reasoning step by step.

Open with SCR (Situation, Complication, Resolution) to set context in 3 sentences before the pyramid.

## Step 3: Write action titles
Every slide title is a full-sentence takeaway (ideally ≤ 2 lines, ~15 words) that states the "so what". The chart below the title proves it.
- ❌ "Revenue by region"
- ✅ "Asia drove 70% of revenue growth since 2022, while Europe stayed flat"

**Horizontal logic test:** reading only the action titles in order should tell the whole story.
**Vertical logic test:** everything on a slide supports its title, and nothing else.

## Step 4: Build the ghost deck
Outline every slide before any formatting:

| # | Action title | Supporting content (chart type / data) | Source | Status |
|---|-------------|----------------------------------------|--------|--------|
| 1 | Executive summary | SCR + 3 key arguments + recommendation | — | |
| 2 | … | Waterfall: profit bridge 2023→2025 | Client finance | Data pending |

Typical structure: Executive summary → Context → Argument sections (one per key argument) → Recommendation & roadmap → Risks → Next steps → Appendix.

Chart guidance: waterfall for bridges, bar for comparisons, line for trends, stacked bar or Marimekko for share/mix, 2×2 for prioritization, Gantt for roadmaps.

## Step 5: Write the executive summary
Either as a slide or as a short memo:
```markdown
**Situation:** …
**Complication:** …
**Recommendation:** …
1. [Argument 1, with the key number]
2. [Argument 2, with the key number]
3. [Argument 3, with the key number]
**Next steps:** decision needed from [audience] by [date].
```

## Quality bar
- The governing thought is stated in the first 30 seconds or the first slide.
- Every title is a sentence with a verb and, ideally, a number.
- No slide without a "so what". Move pure data to the appendix.
- Tailor to the audience: board (decision and risk), operators (how and when), technical (method).
- If the user later wants actual slides, hand off the ghost deck to a slide-building tool or skill.
